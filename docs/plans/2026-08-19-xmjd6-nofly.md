# XMJD6 No-Fly Windows Bundle Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Generate a standalone, Windows-first `xmjd6-nofly/` Rime distribution where `ch` always uses `J`, `zh` always uses `Q`, and `uang` always uses `X`, without modifying the active Rime configuration.

**Architecture:** A deterministic Python builder reads the current source dictionaries, rewrites only structurally identified phonetic positions, collapses duplicate fly-key variants, and copies the required Windows, Lua, OpenCC, and reverse-lookup resources into a fresh output directory. Tests exercise the conversion engine independently, validate the generated bundle, and compile it in a temporary Rime staging directory.

**Tech Stack:** Python 3, `pypinyin`, Rime YAML dictionaries, Windows batch, unittest-compatible Python assertions, local `rime_deployer`.
